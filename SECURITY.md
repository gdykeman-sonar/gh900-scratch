# Security policy

## Supported versions

Security fixes are applied to the latest state of the `main` branch. Older commits and forks do not receive fixes.

| Version | Supported |
| ------- | --------- |
| `main`  | Yes       |
| Other   | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub's private vulnerability reporting:

1. Open the [Security tab](https://github.com/gdykeman/gh900-scratch/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, including the affected file or feature, the steps to reproduce it and the impact you expect.

If you cannot use that form, open a public issue that asks for a private contact route and contains no details of the vulnerability. A maintainer will reply with a way to share it.

## What to expect

- Acknowledgement of your report within 5 business days.
- An assessment and an initial answer within 10 business days.
- Updates as the fix progresses, and credit in the published advisory if you want it.

Once a fix is available, the maintainers publish a security advisory that describes the issue and the fixed state of `main`.

## Scope

This policy covers the contents of this repository: its files, workflows and configuration. Vulnerabilities in GitHub itself belong to GitHub's own program at https://bounty.github.com.
